# Experiments

Keep one self-contained folder per concept: a movement test program, combat study,
or map rendering prototype. Experiments are not production dependencies and do not
imply accepted game rules.

## Catalog

| Experiment | Status | Purpose |
| --- | --- | --- |
| [hex-tiles](hex-tiles/README.md) | Exploratory art | Editable river, road, railroad, and bridge SVGs plus a map mockup |

## Start an experiment

Copy [_template/README.md](_template/README.md) into a descriptive new folder,
fill in its question and run steps, and add it to the catalog. Keep dependencies,
small fixtures, and concept tests in that folder. Ignore generated output.
The template is not an active experiment.

Record findings even if the concept is abandoned. To adopt results, follow
[the promotion guidance](../docs/architecture.md#exploration-to-production).
